# GeoWorld

## 전시하기

1. Chrome 등의 브라우저 실행
2. 주소 입력
  ```
  https://
  ```
3. F11 눌러서 전체 화면으로 만들기

전시 기간 외에 악용 우려로 **사이트 주소 노출되지 않게 주의**
